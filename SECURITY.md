# Security and privacy

Deferral Twin holds very personal data: interview answers, a voice clip and a photo. Please treat issues touching that data as security issues.

## Reporting

Report privately through GitHub's **Security → Report a vulnerability** on this repository. Please don't open a public issue for:

- personal data leaving the machine while Online mode is off
- voice or face features working for someone who did not consent
- ways to make the twin answer confidently with no supporting evidence

## Where data lives

On macOS, everything the app stores lives under `~/Library/Application Support/DeferralTwin/`. Deleting that folder removes the twin completely.
